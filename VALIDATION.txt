made against this independent implementation, not inherited test claims.

ASSEMBLED 16-BIT CODE: PASS
Python Unicorn executes the actual overlay 336 bytes from the rebuilt U7.EXE.
Narrow native-service stubs supply allocation, NPC IDs and RNG. Tests cover:
- Five outgoing/incoming damage factors, native signed 127 cap, zero/negative
  damage, party/party, nonparty/nonparty and absent-attacker exclusions.
- Twenty one-point party hits produce 16 actual damage on Hard and 10 on Avatar.
  Unknown NPC IDs still take minimum one-point damage.
- All six original RNG bounds, all five settings, before/after original flag 3.
  Normal passes the unchanged bound; Game Journalist consumes no RNG.
- Native flag object layout, eligible roster, initialized saved mana, no refill
  of already initialized mana, separate Avatar/companion mana reads/writes.
- Correct far-return stack consumption, BP and FS/GS preservation.
- Fresh book initialization, linked pointers and quality preserved; another
  item shape left unchanged.

NATIVE DOSBOX: OBSERVED
- Five-choice DOS boot selector persists choice and resumes original menu.
- Original Avatar spellbook opens from tactical Cast.
- Jaana requires her own book and reagents. With a learned book and reagents,
  native Light reduces her mana 18 to 17 and leaves +0F/+10 at 0C/0C.

  returns to tactical pause with game clock 10971 unchanged.
- Clearing original generator flag 3 blocks casting with the story-lock text.
- Native SaveUI serializes the initialized mana bytes. Native reload restores
  saved mana 18 after live RAM was set to 3, and Avatar IBO remains 0038.
- Nystul's new topic and native Yes/No confirmation work. Purchase adds one
  book and removes exactly 500 gold: party 10192 to 9692.
- Purchased book data has linear spells FF, no advanced-circle bits, and zero
  bookmark. Initialization was checked in the native item buffer.
- Insufficient gold refuses purchase and creates no book. Declining returns to
  the original conversation and creates no book.

RESOURCES AND INSTALLER: PASS
All 1012 original Usecode records are retained. Only six merchants change;
all original operands and branch destinations are preserved. The added shop
function uses original helpers 90A and 8F8. Rebuilding the two pristine LINKDEP
files reproduces both byte for byte. Patched transitive closures, sizes and
file offsets validate against every output record.

The integration suite verifies all five output hashes on clean installation,
read-only check, idempotent installation, v1.1 upgrade, verified explicit
original backup, exact five-file uninstall, save/config/preference retention,
unknown executables and independently modified resources, backup conflicts,
installation lock, FAT-style backup fallback, replacement failure, and
rollback after three of five replacements were committed.

LIMITS
This is focused native and machine-code verification, not a complete campaign
playthrough. Nystul was the end-to-end native purchase case; the other merchants
received structural checks. SaveUI was invoked through a disposable fixture
for serialization testing; every nested save/load/cancel flow was not replayed.
All five combat settings were tested in assembled-code emulation; full native
encounters on all five settings were not replayed. Old v1.1 runtime scenarios
were not all repeated. Current identities and full machine-code/installer
results are in BUILD.json and VALIDATION.json. No game data or screenshots
are distributed with the patch.
